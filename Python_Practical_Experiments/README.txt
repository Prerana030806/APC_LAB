PYTHON PRACTICAL EXPERIMENTS 1-12

Each experiment is stored in a separate folder with a short title.

Run a regular experiment:
    python experiment_N.py

Dependencies for Experiment 9 and Experiment 10:
    python -m pip install numpy pandas matplotlib

Experiment 11:
    Tkinter is included with many standard Python installations. On some Linux systems, install the python3-tk package.

Experiment 12 - Django Login and Regex Validation:
    Open the Experiment 12 folder in a terminal.
    python -m pip install -r requirements.txt
    python manage.py runserver
    Open http://127.0.0.1:8000/

Experiment 12 validates a demo username and password format using regular expressions. It does not create real user accounts or provide production authentication.

All Python source files are provided without code comments.
